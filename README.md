## Project Description
NetMessenger is a multi-client chat and file-sharing application implemented in C using TCP/IP sockets.

The system will support:
- User registration
- Listing connected users
- Broadcast messaging
- Private messaging
- Chat rooms
- Room messaging
- File transfer
- Graceful disconnect handling
- Error handling
- Server-side logging
